# ✨ Sketch → Image — air-drawing generative art studio

Draw anything in mid-air with your finger in front of the webcam and the app
turns your floating sketch into unique **generative images** (pinch to fire).

Full documentation, setup and AI-backend instructions:
👉 **[sketch_to_image/README.md](sketch_to_image/README.md)**

```bash
cd sketch_to_image
pip install -r requirements.txt
python main.py          # start drawing in the air
python demo.py --ui     # preview without a webcam
```
